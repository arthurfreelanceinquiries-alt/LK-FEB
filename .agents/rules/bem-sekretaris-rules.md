# Rules — Sekretaris BEM FEB UKRIDA
# File ini dimuat otomatis oleh Antigravity sebagai behavioral rules

## Bahasa & Gaya
- Selalu gunakan **Bahasa Indonesia formal** yang sopan dan profesional
- Saat menulis dokumen resmi: hindari bahasa informal/slang
- Saat berkomunikasi dengan user: boleh lebih santai tapi tetap profesional

## Akurasi Keuangan
- **WAJIB** memvalidasi balance RAB sebelum finalisasi dokumen apapun
- Jika RAB tidak balance → STOP → notifikasi user → JANGAN lanjut generate dokumen
- Format rupiah SELALU: "Rp. X.XXX.XXX" (pakai titik ribuan, bukan koma)

## Konsistensi Format
- Nomor bab SELALU Romawi: I, II, III, IV, V, VI
- Sub-poin SELALU huruf kapital: A, B, C
- Sub-sub-poin SELALU angka: 1, 2, 3
- Tanggal SELALU: "Jakarta, DD Bulan YYYY" (nama bulan, bukan angka)

## Second Brain
- **WAJIB** membaca 00_DASHBOARD_SECOND_BRAIN.md di awal setiap sesi
- **WAJIB** mengupdate dashboard setelah setiap sesi produktif
- Simpan semua keputusan penting ke 07_Second_Brain/keputusan/

## Penyimpanan File
- Proposal baru → `01_Proposal/[NAMA_ACARA]_[TAHUN]/`
- SPU → `02_SPU/[NAMA_ACARA]_[TAHUN]/`  
- LPU → `03_LPU/[NAMA_ACARA]_[TAHUN]/`
- Acara selesai → pindah ke `04_Arsip_Acara/[NAMA_ACARA]_[TAHUN]/`
- Hasil audit → `06_Audit_Review/`

## Standar Kualitas
- Setiap proposal HARUS lolos audit checklist sebelum dikategorikan "final"
- Skor audit minimum untuk "SIAP SUBMIT": 8.5/10
- Skor < 7/10 = "PERLU REVISI MAYOR" (wajib perbaiki dulu)
