## Cara Penggunaan
Untuk setiap item, tandai:
- ✅ = Sudah benar/ada
- ⚠️ = Ada tapi perlu perbaikan
- ❌ = Tidak ada / salah

---

## AUDIT PROPOSAL

### 📄 A. Halaman Cover
- [ ] Judul acara lengkap ditulis KAPITAL
- [ ] Nama organisasi: "BADAN EKSEKUTIF MAHASISWA"
- [ ] Nama fakultas: "FAKULTAS EKONOMI & BISNIS UKRIDA"
- [ ] Periode: "PERIODE 2026"
- [ ] Alamat: "Jl. Tanjung Duren Raya no. 4, Jakarta Barat"
- [ ] Telepon dan Fax tercantum

### 📋 B. Struktur Bab
- [ ] BAB I: LATAR BELAKANG ✓ (dengan nomor Romawi "I.")
- [ ] BAB II: TEMA KEGIATAN ✓
- [ ] BAB III: KEGIATAN ✓
  - [ ] A. Tujuan Kegiatan (min. 5 poin)
  - [ ] B. Manfaat Kegiatan (min. 3 poin)
  - [ ] C. Target Peserta
  - [ ] D. Pelaksanaan Kegiatan (hari, tanggal, tempat)
  - [ ] E. Narasumber (jika ada)
  - [ ] F. Susunan Acara/Rundown
  - [ ] G. Games/Kegiatan Khusus (jika ada)
- [ ] BAB IV: KEPANITIAAN ✓
- [ ] BAB V: ANGGARAN ✓
- [ ] BAB VI: PENUTUP ✓

### 🏃 C. Rundown
- [ ] Ada kolom: Waktu | Durasi | Kegiatan
- [ ] Semua baris terisi (tidak ada sel kosong)
- [ ] Durasi dalam menit
- [ ] Format waktu konsisten (HH:MM)
- [ ] Hari terakhir berakhir dengan "Evaluasi"

### 👥 D. Kepanitiaan
- [ ] Pelindung (Dekan) dengan gelar lengkap
- [ ] Penasehat dengan gelar lengkap
- [ ] Ketua BEM FEB + NIM
- [ ] Wakil Ketua BEM FEB + NIM
- [ ] Pengawas + NIM
- [ ] Ketua Pelaksana + NIM
- [ ] Wakil Ketua Pelaksana + NIM
- [ ] Sekretaris + NIM
- [ ] Bendahara + NIM
- [ ] Koordinator tiap sie + NIM
- [ ] Anggota tiap sie + NIM
- [ ] Semua NIM format: 3-4 digit angka + 3 digit angka (mis: 312023002)

### 💰 E. Anggaran / RAB
- [ ] Ada tabel Pemasukan
- [ ] Ada tabel Pengeluaran per divisi
- [ ] Setiap divisi ada TOTAL
- [ ] Ada Rekap Total semua divisi
- [ ] **Total Pemasukan = Total Pengeluaran** (KRITIS!)
- [ ] Sisa = Rp. 0
- [ ] Format rupiah: "Rp. X.XXX.XXX"

### ✍️ F. Penutup & Tanda Tangan
- [ ] Paragraf penutup ada
- [ ] Format tanggal: "Jakarta, DD Bulan YYYY"
- [ ] "Hormat kami,"
- [ ] Tanda tangan Ketua Pelaksana + NIM
- [ ] Tanda tangan Ketua BEM FEB + NIM
- [ ] "Mengetahui,"
- [ ] Tanda tangan Dekan dengan gelar lengkap

---

## AUDIT SPU

- [ ] Nomor surat format standar
- [ ] Tanggal surat
- [ ] Kepada Yth. jelas
- [ ] Detail acara (hari, tanggal, waktu, tempat)
- [ ] Keterangan permohonan jelas
- [ ] Tanda tangan Ketua Pelaksana + Ketua BEM
- [ ] Mengetahui: Dekan

---

## AUDIT LPU

- [ ] Perbandingan rencana vs realisasi (waktu, peserta)
- [ ] Rundown realisasi dengan keterangan ✅/⚠️
- [ ] Evaluasi: hal baik + kendala + saran
- [ ] Laporan keuangan: anggaran vs realisasi per divisi
- [ ] Rekap keuangan akhir
- [ ] Keterangan sisa anggaran (jika ada)
- [ ] Tanda tangan

```
**Auditor:** Antigravity AI

### ✅ Sudah Benar (X item)

- Struktur bab: lengkap I-VI
- ...

- ...

**Rekomendasi:** [SIAP SUBMIT / PERLU REVISI MINOR / PERLU REVISI MAYOR]
```
