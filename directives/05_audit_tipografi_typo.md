## Checklist Audit Tipografi, Margin & Typo

Tandai setiap item: ✅ Benar | ⚠️ Perlu perbaikan | ❌ Salah/tidak ada

---

### 📐 A. Margin (jika bisa diverifikasi dari file Word/Google Docs)

- [ ] **Atas:** 2,5 cm
- [ ] **Bawah:** 2,5 cm
- [ ] **Kiri:** 3,0 cm *(lebih lebar untuk binding)*
- [ ] **Kanan:** 2,5 cm
- [ ] Tidak ada teks yang terpotong di tepi halaman

> *Catatan: Jika hanya punya file Markdown/teks, item ini dilewati (N/A).*

---

### 🔤 B. Font & Ukuran

- [ ] Font utama: **Times New Roman** (bukan Arial, Calibri, dll)
- [ ] Ukuran body text: **12 pt**
- [ ] Ukuran cover: **14 pt Bold**
- [ ] Ukuran header tabel: **11 pt Bold**
- [ ] **Tidak ada perubahan font mendadak** di tengah paragraf
- [ ] **Tidak ada teks highlight warna** yang tertinggal (sisa edit)
- [ ] Judul bab: Bold
- [ ] Sub-poin (A, B, C): Bold
- [ ] Isi paragraf: Regular (tidak bold)

---

### ↕️ C. Spasi & Jarak

- [ ] Spasi isi paragraf: **1,5 spasi** (bukan double, bukan single)
- [ ] Antar paragraf dalam bab: seragam (tidak ada yang double-enter)
- [ ] Sebelum judul bab baru: ada jarak konsisten
- [ ] Setiap bab baru: **mulai halaman baru** (page break)
- [ ] Dalam tabel: spasi single
- [ ] Tidak ada enter/baris kosong berlebihan di awal atau akhir dokumen

---

### ↔️ D. Alignment (Perataan)

- [ ] Paragraf isi: **Justify** (rata kiri-kanan)
- [ ] Cover/judul: **Center**
- [ ] Judul bab: **Rata kiri**
- [ ] Angka dalam tabel: **Rata kanan**
- [ ] Teks deskripsi dalam tabel: **Rata kiri**

---

### 🔢 E. Penomoran & Indentasi

- [ ] Nomor bab format Romawi diikuti titik: `I.` `II.` `III.` — bukan `I)` atau `I:`
- [ ] Sub-poin huruf kapital diikuti titik: `A.` `B.` `C.` — bukan `A)` atau `A:`
- [ ] Sub-sub-poin angka diikuti titik: `1.` `2.` `3.`
- [ ] Indent sub-poin konsisten di seluruh dokumen
- [ ] Poin-poin dalam daftar rata kiri dengan indent yang sama

---

### 🔍 F. Typo & Kesalahan Penulisan

#### F1. Nama Pejabat & Gelar (KRITIS — 0 toleransi)
- [ ] Dekan: `Dr. Diana Frederica S.E., M.Ak., CFP®., CHCP-A` *(ada ® di CFP)*
- [ ] Wakil Dekan: `Dr. Daniel Widjaja, S.E., M.M., CSCU, CEAP`
- [ ] Ketua BEM: `Arthur Reezan` — NIM `312023002`
- [ ] Wakil Ketua: `Princess Auralia Barus` — NIM `322024025`
- [ ] Semua gelar akademik ditulis lengkap dan urut

#### F2. Nama Organisasi
- [ ] `BEM FEB UKRIDA` (bukan BEM UKRIDA / BEM FEB saja)
- [ ] `Fakultas Ekonomi dan Bisnis` (bukan "Ekonomi Bisnis" tanpa "dan")
- [ ] `Universitas Kristen Krida Wacana` (jika ditulis panjang)
- [ ] `Badan Eksekutif Mahasiswa` (jika ditulis panjang, huruf kapital awal)

#### F3. Format Angka & Mata Uang
- [ ] Semua nominal: `Rp. X.XXX.XXX` — ada titik setelah Rp, titik ribuan
- [ ] Tidak ada: `Rp10.000` atau `Rp.10.000` atau `Rp 10.000` (tidak konsisten)
- [ ] Tanggal: `DD Bulan YYYY` — contoh `13 Agustus 2026` (tanpa koma sebelum tahun)
- [ ] Format waktu: `HH:MM` — contoh `08:30` (bukan `8.30` atau `08.30`)
- [ ] Semua NIM 9 digit angka: `312023002` ✓

#### F4. Ejaan Bahasa Indonesia Umum
Cek apakah ada kata-kata berikut (jika ada → FLAG sebagai typo):

| Cari | Ganti Dengan |
|------|-------------|
| `praktek` | `praktik` |
| `sistim` | `sistem` |
| `analisa` | `analisis` |
| `aktifitas` | `aktivitas` |
| `nomer` | `nomor` |
| `sekedar` | `sekadar` |
| `merubah` | `mengubah` |
| `mahsiswa` | `mahasiswa` |
| `kegiatan-kegiatan` | `berbagai kegiatan` *(hindari pengulangan)* |
| `dll,` | `dll.` *(titik, bukan koma)* |

#### F5. Konsistensi Istilah
- [ ] Nama tema ditulis sama di semua kemunculan (cover, bab II, penutup)
- [ ] Nama acara ditulis konsisten (tidak berganti-ganti singkatan)
- [ ] "Mahasiswa baru" atau "mahasiswa Baru" — pilih satu, konsisten
- [ ] "Sie" atau "Seksi" — pilih satu, konsisten

---

### 📊 G. Tabel

- [ ] Semua tabel punya header baris pertama
- [ ] Tidak ada sel yang kosong tanpa keterangan `-` atau `N/A`
- [ ] Lebar kolom proporsional (kolom "No" tidak sama lebar dengan kolom "Keterangan")
- [ ] TOTAL/Grand Total ada di baris terakhir setiap tabel anggaran
- [ ] Kata TOTAL ditulis kapital semua dan **bold**

---

### 📝 H. Cover & Header Dokumen

- [ ] Semua teks cover KAPITAL SEMUA
- [ ] Alamat lengkap: `Jl. Tanjung Duren Raya no. 4, Jakarta Barat` *(huruf "no" kecil)*
- [ ] Telepon: `021 566 6952` *(spasi, bukan 021-566-6952)*
- [ ] Fax: `021 566 6956`
- [ ] Tidak ada typo di kop surat

## Cara Melaporkan Hasil Audit Tipografi

Tambahkan ke laporan audit utama (setelah audit struktur):

```
### 🖋️ AUDIT TIPOGRAFI & TYPO

#### ✅ Lolos (X item)
- Font Times New Roman konsisten
- Alignment justify di seluruh isi
- Nama Dekan: Dr. Diana Frederica S.E., M.Ak., CFP®., CHCP-A ✓

#### ⚠️ Perlu Perbaikan (X item)
- Halaman 5: spasi paragraf tidak konsisten (ada yang single, ada yang 1.5)
  → Samakan semua menjadi 1.5 spasi
- Tabel anggaran: kolom angka rata kiri, seharusnya rata kanan
  → Ubah alignment kolom Total ke rata kanan

#### ❌ Harus Diperbaiki (X item)
- Halaman 8: "praktek" → seharusnya "praktik"
- Halaman 12: "Rp.1.125.000" → seharusnya "Rp. 1.125.000" (ada spasi)
- Cover: nama Dekan tanpa gelar CFP® → tambahkan gelar lengkap

### 📊 Skor Tipografi: X/10
[LOLOS / PERLU REVISI MINOR / PERLU REVISI MAYOR]
```

## Integrasi dengan Audit Utama

Urutan audit lengkap dokumen BEM FEB UKRIDA:

```
1. Audit Struktur & Isi    → directives/04_audit_checklist.md
2. Audit Tipografi & Typo  → directives/05_audit_tipografi_typo.md  ← FILE INI
3. Hitung Skor Gabungan    → (Skor Isi × 0,6) + (Skor Tipografi × 0,4)
4. Keputusan Final         → SIAP SUBMIT / REVISI MINOR / REVISI MAYOR
```

**Bobot Skor:**
- Audit Isi/Struktur: **60%** dari skor akhir
- Audit Tipografi/Typo: **40%** dari skor akhir
- Minimum skor gabungan untuk "SIAP SUBMIT": **8,5/10**
